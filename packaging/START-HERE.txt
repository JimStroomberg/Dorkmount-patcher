Dorkmount Patcher — Linux beta

This app only patches your keyboard. It does not include widgets.
Dorkmount, the separate widget app, is coming soon.

CachyOS x86-64: installation, restoration and Dashboard confirmed on the test
keyboard. Ubuntu 26.04 x86-64: package checks pass; real-machine testing pending.
The portable bundle needs glibc 2.41+ and the graphics/C++ libraries listed in
docs/DEPENDENCIES.md. Native packages install their declared dependencies.

1. Extract the entire archive and run Dorkmount-patcher.
2. Close other keyboard apps and connect the keyboard, screen and number pad.
3. Follow Check keyboard → Prepare update → Install Dashboard → Verify.
4. Close the updater, select Dashboard on the keyboard and start a compatible
   widget app. Waiting… remains until drawing starts. Double-click Menu to leave.

If access is denied, use Set up USB access and reconnect after the password prompt.
Do not run the app as root. The app downloads the supported official firmware and
prepares it locally; no Python setup, compiler or companion is needed for patching.

Keep power and cables connected during updates. If an update stops, preserve the
session and consult docs/TROUBLESHOOTING.md before attempting another operation.

Installation and stock restoration: docs/INSTALLING.md
Troubleshooting: docs/TROUBLESHOOTING.md
Developer guide: docs/DEVELOPERS.md
To preview without keyboard access: ./Dorkmount-patcher --demo

Full firmware and session records stay in your local state directory, normally
~/.local/state/dorkmount-patcher. Please keep that folder private. Uninstalling
the app does not remove those files or restore the keyboard's original firmware.
