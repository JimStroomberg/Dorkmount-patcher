Dorkmount screen updater — Linux test release

For a current Linux x86-64 desktop (including CachyOS). The bundle is built on
Debian 13 and needs glibc 2.41+ and the desktop's graphics/C++ runtime libraries.

1. Extract the entire archive to a folder in your home directory.
2. Open that folder and run Dorkmount-patcher.
3. Close other keyboard apps and connect the keyboard, screen and number pad.
4. Follow Check keyboard → Prepare update → Install → Verify.

If keyboard access is denied, choose Set up USB access. Your desktop asks for
your administrator password once. Reconnect the keyboard afterward.

This preview has been tested without a physical keyboard. Its new installer
still needs a real-keyboard trial. A failed firmware update can make the keyboard
unusable. Do not unplug it, let the computer sleep or close the app mid-update.

The app downloads the supported official firmware and prepares your update
locally. You do not need Python, a compiler, Dorkmount or IO Center installed.
Internet access is needed the first time firmware files are prepared.

After successful installation, close the updater, open a compatible application
and select Clock on the keyboard screen. Double-click Menu to leave that view.

To explore the interface without any keyboard access:
    ./Dorkmount-patcher --demo

Testing and trouble recovery: docs/TESTING.md
Developer guide: docs/DEVELOPERS.md
The reference examples need a separate Python environment; the updater does not.

All downloaded firmware and update records remain in your personal local state
directory (normally ~/.local/state/dorkmount-patcher). Do not upload that folder
or full firmware images to GitHub. Uninstalling the app does not delete them.
