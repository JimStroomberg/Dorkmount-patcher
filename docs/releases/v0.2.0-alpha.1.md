# First Linux installer alpha

This is an experimental build for testing the new native updater. **No physical
keyboard update has yet been completed with this installer.** The DMR2 patch
reproduces the previously tested firmware bytes, but installation, restoration,
real USB access/reconnection and interruption recovery still need hardware tests.
A failed update can make the keyboard unusable.

## Downloads

- **Ubuntu 26.04 x86-64:** download the `.deb` and open it with the graphical package installer. It installs declared dependencies and the keyboard-access rule.
- **Current CachyOS x86-64:** download the `.pkg.tar.zst` and install it as a local package. Use your graphical package manager if it supports local files, or use the command below. The package manager installs declared dependencies and the keyboard-access rule.
- Reconnect the keyboard after installation, then open **Dorkmount Patcher** from the application menu. Its desktop shortcut also offers a hardware-free demo.
- The `.tar.gz` desktop bundle is a portable alternative with manual dependency/USB setup. The source archive and Python wheel are intended for developers.

macOS on Apple Silicon and Bazzite are **Coming soon**. Windows is planned later.
Container package checks do not constitute validation of a full desktop session.

If opening the download does not offer an installer, open a terminal in the
download folder and use the command for your system. Confirm the password and
package installation when asked.

Ubuntu:

```sh
sudo apt install './dorkmount-patcher_0.2.0~alpha1-1_amd64.deb'
```

CachyOS:

```sh
sudo pacman -U ./dorkmount-patcher-0.2.0alpha1-1-x86_64.pkg.tar.zst
```

## Included

- Guided Check → Prepare → Install → Verify workflow, local stock restoration files and a failure journal.
- Exact original/input/output hash checks and a compiler-free DMR2 patch engine.
- Independent DirectDraw protocol documentation, offline in-app guide and Python examples.
- Native Linux package definitions, source-build/dependency instructions, and an automated PR/release workflow.

Read [the hardware test procedure](https://github.com/JimStroomberg/Dorkmount-patcher/blob/v0.2.0-alpha.1/docs/TESTING.md) before attempting installation. Close other keyboard controllers and keep the screen and number pad attached. If a transfer cannot be verified, keep the keyboard connected and preserve its local session folder; do not blindly retry.

No manufacturer firmware or complete patched image is included. The application
obtains and verifies the exact official files locally. Never attach full firmware
or session directories to an issue.
