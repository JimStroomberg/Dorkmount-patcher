# 0.2.0-alpha.3 — Dashboard candidate

**Unreleased development candidate. No real-keyboard validation yet.**
Published alpha.2 packages contain DMR2 and do not include this Dashboard view.

The candidate replaces Clock's selector tile with a monitor/bar-chart icon and
opens directly to **Waiting…**. A compatible companion draws over that screen;
the old clock/timer/stopwatch submenu is bypassed. Left/Right and double-click
Menu keep the established navigation behaviour.

The updater prepares DMR3 by default and verifies that exact capability version
after an installation. DMR1/DMR2 sources remain unchanged. Manufacturer versions
still report 1.29.0; developers should use DMR capabilities to detect the patch.
Clients that only recognize DMR1/DMR2 need an update before using DMR3.

The Linux bundle now finds the system certificate bundle when its build-time
OpenSSL certificate path is absent. Explicit trust-store overrides remain in
effect and certificate/hostname verification stays enabled. A new
`prepare --download --output PATH` command exercises the verified download and
preparation path without opening a keyboard; `--restore` prepares stock images.

Use [the source/local package guide](../BUILDING.md) and
[hardware test guide](../TESTING.md) for a candidate trial. Offline validation is
recorded in [VALIDATION.md](../VALIDATION.md). Native installation/restoration,
physical display behaviour and recovery remain unverified. No automatic return
to Waiting… is implemented when the companion stops.

Planned packages retain Ubuntu 26.04 and current stable CachyOS x86-64 as the
initial targets. Apple Silicon macOS and Bazzite remain Coming soon; Windows
follows later. Full manufacturer and patched firmware images stay local.
