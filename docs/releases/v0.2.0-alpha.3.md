# 0.2.0-alpha.3 — Dashboard and reliable Linux downloads

This updater only patches your keyboard. Widgets come from a separate compatible
app. [Dorkmount](https://github.com/JimStroomberg/Dorkmount), the companion app,
is **coming soon**; it is not included in this installer.

This alpha adds the **Dashboard icon and Waiting… view**, with native
installation, stock restoration and reinstallation confirmed by the maintainer
on a CachyOS test machine and supported Dark Mount keyboard.

## What changed

- The Clock tile becomes Dashboard. Opening it skips the clock/timer/stopwatch
  submenu; a compatible companion supplies the screen contents.
- DMR3 identifies the Dashboard extension separately from manufacturer 1.29.0.
  Left/Right navigation and double-click Menu remain available.
- Fixed certificate errors when downloading firmware in the packaged Linux app.
  Downloads use the system certificate store and keep certificate checks enabled.
- `prepare --download` checks official download and patch preparation without
  opening a keyboard. Demo and screenshot options cannot start preparation.

## Download and install

| Package | Use |
|---|---|
| `dorkmount-patcher-0.2.0alpha3-1-x86_64.pkg.tar.zst` | CachyOS x86-64; maintainer-confirmed hardware workflow |
| `dorkmount-patcher_0.2.0-alpha3-1_amd64.deb` | Ubuntu 26.04 x86-64; real-machine verification pending |
| `Dorkmount-patcher-0.2.0a3-linux-x86_64.tar.gz` | Portable Linux bundle; dependencies/access setup are manual |

Matching source, a reference-client wheel, checksums and build metadata accompany
the packages. Follow [installation/restoration](https://github.com/JimStroomberg/Dorkmount-patcher/blob/v0.2.0-alpha.3/docs/INSTALLING.md). The native
packages install declared libraries through the system package manager.
No manufacturer firmware is included in downloads.

## Validation and limitations

The maintainer confirmed installation, restoration, reinstallation, the Dashboard
icon and waiting screen, companion graphics/navigation, normal keyboard behaviour,
reconnect and app restart on CachyOS. Disconnect experiments also passed in the
reported tests. This does not guarantee recovery at every interruption point or
from a nonbooting keyboard. [Full validation scope](https://github.com/JimStroomberg/Dorkmount-patcher/blob/v0.2.0-alpha.3/docs/VALIDATION.md)

Ubuntu 26.04 package/container checks pass; real-machine installation and keyboard
verification remain pending. Apple Silicon macOS and Bazzite are **Soon**;
Windows is later. Only model 1/revision 1 with the exact supported 1.29.0 images
is accepted. The Media Dock and Numpad must be attached.

Companions must recognize DMR3 and repaint completely after Dashboard entry.
Older strict DMR1/DMR2 companions need updating. Live drawing on the eight display
keys, atomic frame swaps and an automatic return to Waiting… when the companion
stops are not implemented. [Developer guide](https://github.com/JimStroomberg/Dorkmount-patcher/blob/v0.2.0-alpha.3/docs/DEVELOPERS.md)

Alpha.1 and alpha.2 contain the older DMR2 Clock-based extension and are superseded
by this release.
