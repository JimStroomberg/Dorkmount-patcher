# Reporting a security problem

If you find a security problem in Dorkmount Patcher, please use
[GitHub's private reporting form](https://github.com/JimStroomberg/Dorkmount-patcher/security/advisories/new).
This gives us a chance to investigate before the details are public.

Include the app version, operating system, what happened and how to reproduce it.
Please leave out personal information, firmware files and full update logs.
Security fixes are made against the latest release.

If private reporting is unavailable, open an issue asking for a private contact
route, without including the vulnerability details.

For ordinary bugs, installation help or feature requests, use
[Issues](https://github.com/JimStroomberg/Dorkmount-patcher/issues).
